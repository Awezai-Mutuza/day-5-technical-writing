## Title: How to Create a GitHub Repository and Make Your First Commit

## 1. Introduction

This guide explains how a beginner can create a GitHub repository, connect it to a computer, and make their first commit using Git.

## 2. Prerequisites

Before starting, you need:

- A computer with Windows operating system.
- An internet connection.
- A GitHub account.
- Git installed on your computer.
- Visual Studio Code installed.
- Basic computer skills.

## 3. Step-by-Step Procedure

### Step 1: Open a web browser.

Expected result: The browser opens successfully.

### Step 2: Visit https://github.com.

Expected result: The GitHub homepage appears.

### Step 3: Sign in to your GitHub account.

Expected result: Your GitHub dashboard appears.

### Step 4: Click the New Repository option.

Expected result: The repository creation page opens.

### Step 5: Enter the repository name.

Expected result: The repository name appears in the name field.

### Step 6: Select Public as the visibility option.

Expected result: The repository will be publicly accessible.

### Step 7: Select Add a README file.

Expected result: GitHub is configured to create a README file.

### Step 8: Click Create Repository.

Expected result: Your new repository is created.

### Step 9: Open the repository's Code menu.

Expected result: Cloning options appear.

### Step 10: Copy the HTTPS repository URL.

Expected result: The repository URL is copied.

### Step 11: Open Git Bash.

Expected result: The Git Bash terminal opens.

### Step 12: Navigate to your project folder.

Expected result: The terminal displays the selected folder location.

### Step 13: Run the git clone command with your repository URL.

Expected result: A local copy of your repository is created.

### Step 14: Open the cloned folder in VS Code.

Expected result: The repository files appear in VS Code.

### Step 15: Create a file named index.html.

Expected result: The new HTML file appears in the Explorer panel.

### Step 16: Add HTML content to the file.

Expected result: The file contains your HTML code.

### Step 17: Save the file.

Expected result: The changes are saved.

### Step 18: Open the VS Code terminal.

Expected result: The terminal appears at the bottom of VS Code.

### Step 19: Run git add .

Expected result: The new file is added to the staging area.

### Step 20: Run git commit -m "My first commit".

Expected result: Git records your first commit.

### Step 21: Run git push origin main.

Expected result: Your changes are uploaded to GitHub.

### Step 22: Refresh your GitHub repository page.

Expected result: The index.html file appears in your online repository.

## 5. Troubleshooting

Problem: Git is not recognized as a command.

Cause: Git may not be installed correctly or may not have been added to the system PATH.

Solution:

1. Download Git from https://git-scm.com/downloads.
2. Install Git.
3. Restart VS Code.
4. Open the terminal.
5. Run git --version to confirm installation.

## 6. Conclusion

Creating a GitHub repository helps developers store, manage, and share their projects. Making a first commit helps beginners understand how Git tracks changes.
